# Dennison Blackett — BluesPrince 🎷

Saxophonist who builds. I make **[THIRI](https://thiri.ai)** — a deterministic music-theory engine for the AI era.

**Computed, not hallucinated.** LLMs guess at harmony; THIRI calculates it. Chord analysis, Roman-numeral analysis, voicing, and reharmonization as exact answers your AI tools can call.

## Try it in two minutes

**In Claude** — Settings → Connectors → Add custom connector → `https://mcp.thiri.ai/mcp`

**In Claude Code / Cursor:**

```bash
npx @bluesprincemedia/thiri-mcp
```
